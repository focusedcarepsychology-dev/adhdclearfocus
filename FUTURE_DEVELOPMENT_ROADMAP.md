# ADHDclearfocus future development roadmap

The current package is designed to keep costs low while improving trust, UX, security and completeness. The roadmap below is ordered by highest return per euro.

## Stage 1 — Free/high-impact improvements

1. Add real testimonials only when permission is explicit.
2. Create short demo videos using screen recording rather than paid production.
3. Add email automations in Mailchimp: welcome, report explanation, 7-day strategy sequence.
4. Add Search Console and submit `sitemap.xml`.
5. Add Microsoft Clarity or a free privacy-conscious session replay alternative only after privacy review.
6. Add lightweight A/B tests manually with query parameters and GA4 events.
7. Add a support FAQ page to reduce email workload.
8. Add printable PDF worksheets generated from static HTML.

## Stage 2 — Low-cost product upgrades

1. Replace JSONBin with Supabase, Neon, Turso or Upstash only when the free-tier JSONBin limits are hit.
2. Add a proper moderation queue for the community.
3. Add saved report history for logged-in users.
4. Add weekly AI summaries from diary and check-ins.
5. Add a Pro plan at a low recurring price after users already love the free product.
6. Add clinician/referrer landing pages.
7. Add school/university/workplace landing pages.

## Stage 3 — Trust and clinical governance

1. Formal clinical safety statement.
2. Data protection impact assessment.
3. Content review log.
4. Moderation policy.
5. Risk escalation policy.
6. Evidence base page with citations and review dates.
7. Clear separation between educational platform and any clinical consultation services.

## Stage 4 — Premium experience

1. Replace CDN Babel in production with precompiled React only if budget/time allow; the current brief says no build step, so do not do this without explicitly changing the architecture.
2. Add interactive report dashboard.
3. Add longitudinal tracking graphs.
4. Add user-controlled AI memory.
5. Add reminders and calendar integration.
6. Add native app wrapper only after product-market fit.

## Stage 5 — Revenue expansion

1. Clinician affiliate/referral model.
2. Employer workplace-adjustment toolkit.
3. University ADHD support package.
4. Licensed white-label version.
5. API/report generation service for clinics.
6. Group focus rooms for schools and workplaces.

## Golden rule

Do not spend money until a free or low-cost version proves engagement. The next paid development should be chosen by data: completion rate, checkout conversion, email signups, repeat dashboard use, focus-room sessions and community posts.
